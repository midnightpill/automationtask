# automationtask
Python script

# How to Run
This project contains three Python tasks.

## Requirements
* Python 3 installed on your computer.
* No additional packages or imports are required.

## Task 1 — Check a Number
File: `task01.py`

Run:
```bash
python task01.py
```
Enter a number when prompted.

If the number is greater than `7`, the program will print:
```text
Hello
```

Example:
```text
Input: 10
Output: Hello
```

---

## Task 2 — Check a Name
File: `task02.py`

Run:
```bash
python task02.py
```
Enter a name when prompted.

If the name is `John`, the program will print:
```text
Hello, John
```

Otherwise, it will print:
```text
There is no such name
```

Example:
```text
Input: John
Output: Hello, John
```

---

## Task 3 — Find Multiples of 3
File: `task03.py`

Run:
```bash
python task03.py
```

Enter numbers separated by spaces.

The program will output the numbers that are multiples of `3`.

Example:
```text
Input: 1 3 5 6 8 9 10
Output:
3
6
9
```

## Running the Files

Each task is a separate Python file:
```text
task01.py
task02.py
task03.py
```

Open a terminal in the project folder and run the files individually using:
```bash
python task01.py
python task02.py
python task03.py
```
